# Arşiv: eski planlar ve mimari belgeler

Bu klasördeki belgeler geçmiş planlardır; **yürürlükte değildir**. Kararların neden
alındığını görmek için saklanır. Yürürlükteki belgeler kök dizindedir:

- `PLAN_V10.md`: ürün odağı (pilot: pazartesi nakit cevabı).
- `PLAN_V11.md`: mimari yol haritası.
- `CLAUDE.md`: proje yasaları. `PRODUCT.md`, `DESIGN.md`: ürün ve tasarım ilkeleri.
- `INTERNATIONAL_PLATFORM.md`: yerel ayar / i18n platformu (`scripts/proof.sh` kökte olmasını denetler).

Operasyon belgeleri `docs/ops/` altındadır (`kubernetes.md`, `managed-postgres.md`);
veri sözleşmeleri `docs/data-contracts.md`'dedir.

Arşive taşınma: 2026-11-14, plan v10 G21 / plan v11 A0.9. İçerik değiştirilmedi;
belgelerin içindeki birbirine atıflar aynı klasörde kaldıkları için geçerlidir.
